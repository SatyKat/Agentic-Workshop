- (capability) CAP-1: Triage decision schema. Every decision is JSON with category (billing|bug|access|performance|how-to), priority (P1-P4), route (team-specific), and one-sentence rationale. Anything else rejected with clear error.
- (capability) CAP-2: Seed data loader. One command 'uv run python load_seed.py' loads seed/tickets.csv and seed/customers.csv into local SQLite app.db as tables 'tickets' and 'customers' with same columns. Running twice produces identical database (idempotent).
- (constraint) Python 3.12 or newer, managed with uv package manager.
- (constraint) seed/ directory is read-only. No changes to seed/tickets.csv or seed/customers.csv.
- (constraint) No network calls and no API keys in this epic. All work is local.
- (constraint) mcp/triage_server.py already reads app.db; its table and column names must stay compatible. No schema changes that break the MCP server.
- (note) Non-goals: Agent, MCP tools, evals, and UI. This epic is data and schema only.
